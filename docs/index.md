# Xev Project Documentation

All agents must read these files before making changes to the project.

## Documents

| Document | Purpose |
|----------|---------|
| [structure.md](./structure.md) | Project file structure and module responsibilities |
| [architecture.md](./architecture.md) | System architecture, data flow, and design patterns |
| [decisions.md](./decisions.md) | Implementation decisions that constrain future work |

## Updating

When making changes to the project:

1. **Structural changes** (new files, moved files, renamed modules) → update `structure.md`
2. **Architectural changes** (new data flow, changed request lifecycle, new integrations) → update `architecture.md`
3. **Implementation decisions** (new conventions, trade-offs, patterns to follow) → add to `decisions.md`

Do not create new documents without adding a link here.
